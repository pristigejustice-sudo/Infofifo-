# Infifo – Smart Opportunity Search

Infifo helps job seekers and students find verified jobs and scholarships worldwide – Nigeria, UK, Germany, Remote, and more. No more random links or outdated listings. Just clean, human‑like answers.

## Features
- 🔍 Search jobs & scholarships
- 🎯 Filter by location, category, field
- ✅ Verified opportunities badge
- 🌍 Local + international opportunities
- 💰 Freemium: 3 free searches/day, then upgrade (₦500 one‑time or ₦1,500/month)
- 💳 Real payments via Flutterwave
- 📱 Mobile‑friendly design
